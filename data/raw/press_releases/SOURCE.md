# Source of these files

27 index-review press releases published by NSE Indices Ltd (niftyindices.com),
announcing changes to the Nifty 100 and Nifty Midcap 100. Each file keeps its original
publisher filename, which carries the release date (`ind_prsDDMMYYYY.pdf`).

They are copyright NSE Indices Ltd. They are included unmodified, only as the evidence for the
point-in-time membership reconstruction (`src/membership.py`, `docs/DECISIONS.md` A17). Without
them, nobody who did not run the original collection could audit that reconstruction.
